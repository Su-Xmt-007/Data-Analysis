
🏥 Health Care Data Analysis & ICU Performance Dashboard

A Complete End-to-End Analytics Project Using Power BI

📌 Project Overview

This project analyzes 24K+ patient records collected between 2017–2019 to understand hospital performance, disease trends, ICU utilization, and patient demographics.
A full Power BI dashboard was built to uncover actionable insights for healthcare decision-making, resource allocation, and operational improvement.

🚀 Key Features
✔ Comprehensive hospital-level insights

Total admissions

Month-wise & weekday-wise trends

Emergency vs OPD distribution

Rural vs Urban population load

✔ Demographic & Disease Analysis

Gender distribution

Age group segmentation

Smoking/Alcohol behavior

Top diseases (BP, Diabetes, CKD, etc.)

Disease patterns by gender and area

✔ ICU Performance & Critical Care Insights

Year & Month-wise ICU admissions

Average ICU length of stay

Disease-wise ICU burden

ICU stay distribution (0–15+ days)

🛠️ Technologies Used

Power BI Desktop

Power Query (ETL)

DAX (Data Analysis Expressions)

Excel (Source Data)

🧹 Data Cleaning & Transformation

Performed using Power Query:

Removed duplicates & nulls

Corrected data types (dates, durations, numeric fields)

Standardized categorical fields (Gender, Rural/Urban, Admission Type)

Converted medical flags (0/1 → Yes/No)

Created calculated columns:

AgeGroup

WeekDayName

WeekDayNumber

ComorbidityCount

StayDays

📐 Data Modeling

Designed using star schema:

Fact Table

Patient Details (24K+ rows)

Dimension Table

Date table with Year, Month, MonthName, WeekName, DayName

Key Measures (DAX)

Total Patients

Male % / Female %

Avg Stay Duration

Avg ICU Stay

Total ICU Patients

Disease Counts

Emergency vs OPD ratio

🔍 Key Insights

63% patients were male; 36% female

67% patients came from rural areas

70% cases were emergencies

Admissions peaked in January & December

Lowest admissions on weekends (Sat–Sun)

Highest disease load: BP, Diabetes, Alcohol, Smoking, CKD

ICU stays were longest for Kidney + Cardiac patients

🧭 Recommendations

Strengthen cardiac & renal care units

Increase staffing during Jan–Feb–Dec

Improve weekend staffing for emergencies

Launch lifestyle disease prevention in rural areas

Enhance chronic disease screening (BP, Sugar, CKD)
